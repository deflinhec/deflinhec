## 工程理念

**先理解問題，優先採用與整合，而非重新發明輪子。** 我傾向善用成熟技術、經過驗證的設計模式與既有工具，避免不必要的重複開發。重點是將適合的元件整合成簡單、易維護且符合實際商業需求的解決方案；只有當現有選擇無法滿足需求時，才自行打造新的技術。我重視務實取捨、可靠性與開發者體驗，勝過追逐技術流行。
